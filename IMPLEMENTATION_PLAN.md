# Проект: NeuroSteps — Эволюция ходьбы 🧪

Проект завершен и готов к использованию локально на вашем MacBook M3.

## 🚀 Как запустить
1. Убедитесь, что вы находитесь в директории проекта:
   `cd /Users/dmitrijsibanov/Desktop/My_projects/NeiroProjects/NeiroSteps`
2. Запустите сервер разработки:
   `npm run dev`
3. Откройте в браузере: `http://localhost:5173`

## 🧠 Что реализовано
- **Физика (Rapier2D):** Полноценная 2D симуляция с суставами-шарнирами и ограничителями вращения.
- **Нейросети (TF.js):** Каждое существо имеет свой "мозг" (MLP), который обучается управлять мышцами на основе сенсорных данных.
- **Генетический алгоритм:** 
  - Каждые 15 секунд происходит смена поколений.
  - Лучшие особи (Top 20%) выживают и дают потомство с мутациями.
  - Динамические графики отслеживают рост "приспособленности" (fitness).
- **Интерфейс:**
  - Glassmorphism дизайн.
  - Визуализация "лаборатории" с трейлами за лидером и звездным небом.
  - Адаптивная камера.

## 🛠 Технические детали (для M3)
- Используется **ESNext** и **WASM** для максимальной производительности на чипе M3.
- Нейросети работают локально в браузере, не требуя внешних API.
- Частота физики зафиксирована на 60Hz для стабильности обучения.
