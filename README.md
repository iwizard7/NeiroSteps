# 🧬 NEUROSTEPS — Evolutionary Locomotion Lab

**Симуляция нейроэволюции существ**, которые самостоятельно учатся ходить, используя генетические алгоритмы прямо в браузере — локально, без интернета и облаков.

## 🤖 Как это работает

### Существо
Каждое существо состоит из:
- **Торса** — главное тело
- **2 бёдер** + **2 голеней** — сочленённые через суставы с ограничителями вращения
- **Нейросети-контроллера (MLP 11→16→4)** — получает сенсорные данные, управляет мышцами

**Сенсоры (11 входов):**
- Вращение и скорость торса (4 значения)
- Углы поворота всех 5 частей тела
- Датчики касания земли — левая/правая нога

**Мышцы (4 выхода):** угол моторов — левое/правое бедро и левое/правое колено

### Эволюционный алгоритм
1. **Симуляция** — выбранная популяция (`1` или `12`) проходит эпизод длительностью 15 секунд
2. **Оценка (Fitness)** — награда за движение вправо с штрафом за уход в минус по X
3. **Селекция** — в режиме `12` выживает верхняя четверть (элитизм)
4. **Мутация** — потомки получают случайные изменения весов нейросети
5. **Новое поколение** — цикл повторяется

В режиме **`1 робот`** используется отдельный solo-цикл: сохраняется лучший мозг и в следующее поколение идёт его мутированная версия.

## 🎮 Управление интерфейсом

| Элемент | Действие |
|---|---|
| **Пауза / Пуск** | Остановить / возобновить симуляцию |
| **⚡ (молния)** | Принудительно закончить текущее поколение |
| **Обучение: 1 робот / 12 роботов** | Выбрать размер популяции для обучения |
| **Экран: Лидер / Все** | Показывать одного лидера или всех существ (в режиме `1` доступен только лидер) |
| **1× / 2× / 4×** | Скорость симуляции (количество физ. шагов за кадр) |
| **💾 Сохранить / 📁 Загрузить** | Кнопки в правом верхнем углу панели «Прогресс обучения» |

## 💾 Сохранение и загрузка

Прогресс сохраняется в **JSON-файл** на ваш компьютер (`neurosteps_genX.json`).

**Для продолжения с того же места:**
1. Нажмите **«Сохранить»** (в панели графика) — файл скачается автоматически
2. Закройте браузер/ноутбук
3. Запустите `npm run dev` снова
4. Нажмите **«Загрузить»** (в панели графика) и выберите ваш файл
5. Симуляция продолжится с того же поколения и теми же «мозгами»!

## 🛠 Технологический стек

| Компонент | Технология |
|---|---|
| UI Framework | React 19 + Vite 8 |
| Физический движок | Rapier2D (WASM, `@dimforge/rapier2d-compat`) |
| Нейронная сеть | Чистый JS (MLP без зависимостей) |
| Рендеринг | Canvas API с ResizeObserver |
| Графики | Кастомный SVG-график (без Recharts) |
| Шрифты | Inter (Google Fonts) |
